全景时间线

阶段 0 · 伤害结算

LivingIncomingDamageEvent —— 可取消（伤害尚未发生） 盾牌/盔甲/吸收 → LivingDamageEvent.Pre（可改伤）→ 扣血 → LivingDamageEvent.Post [A] 倒地中免伤规则 / 过量伤害追踪（Pre @LOWEST）
▼ 伤害结算后 health ≤ 0

阶段 1 · 濒死瞬间（原版无中间状态）

health ≤ 0（同 tick 内继续走，不产生可停留状态） checkTotemDeathProtection —— 图腾关卡（宣告死亡前的最后回滚点） [D] 扩充图腾来源与种类（机制与原版图腾同关卡） 图腾生效 → health=1 回滚（死亡未宣告，可反复触发）

图腾救活 ⇒ die() 根本不会被调用 ⇒ 死亡事件不产生 ⇒ 互助/掉落全程无感。

▼ 图腾耗尽，进入 die()

阶段 2 · 死亡宣告（LivingDeathEvent，每次死亡仅派发一次）

ServerPlayer.die → LivingDeathEvent 派发（HIGHEST→LOWEST） [A] @HIGHEST 取消宣告 → 进入濒死 濒死状态（模组私有 capability；玩家存活，队友可右键救助） [MVE] @HIGHEST 快照 + 冻结经验（宣告被取消则同步回滚） [C] @LOWEST 死亡快照（位置/物品栏/经验，供墓碑与讣告使用）
▼ 无人取消（或 A 倒计时结束 kill() 重入本阶段）
发送 CombatKill 包 —— 客户端此刻进入死亡屏（早于掉落完成） 真实死亡（health≤0，躺尸原地）
▼ 进入掉落管线 dropAllDeathLoot

阶段 3 · 掉落管线（captureDrops 窗口 → LivingDropsEvent）

captureDrops 开始 → inventory.dropAll（keepInventory 门控） [B·同类] 灵魂绑定类：dropAll HEAD 预留下架（物品不入池），RETURN 原位放回 经验球生成（早于物品掉落事件；数量 = min(等级×7,100)，MVE 冻结后为 0） LivingDropsEvent 派发 —— 唯一统一的物品接管窗口（优先级阶梯见下） 事件结束 → 剩余集合 addFreshEntity（＝“物品掉落完成”）
▼ 掉落完成

阶段 4 · 死后状态与重生

已死未重生（躺在死亡点，等待玩家操作） 点重生 → Clone（PERSISTED_NBT 随之拷贝）→ PlayerRespawnEvent [B] 重生时还原被回收的物品/经验 [MVE] 重生时返还已保留的物品

阶段 3 内部：LivingDropsEvent 优先级阶梯

@HIGHEST饰品保留（Curios + 不掉落附魔谓词）——保留物不入池
@NORMAL[B] 条件回收：掉落池中出现 Protector/触发物 → 整体回收全部物品 + 取消经验
@LOW[MVE] fate diff → 托管（缺席者＝自有归属，自动让位；池空则整体中止）
@LOWEST[C] 墓碑收集：processDrops 匹配死亡快照 → removeDrops 清空集合
事件结束剩余物品 addFreshEntity —— 真正落地

场景走查：怕死的玩家

1
致命一击　伤害结算完成，health ≤ 0。
2
图腾 D 逐个生效　半背包图腾在濒死瞬间反复回滚（每次 health=1），直到耗尽。
3
互助 A 接管　死亡宣告被取消 → 进入濒死状态，队友可救助；若获救：复活，后续所有模组全程无感。
4
无人救助 → 血流殆尽　kill() 以 BLED_TO_DEATH 伤害源重新走一遍完整死亡管线，这次无人取消 → 真实死亡宣告。
5
MVE 快照冻结　C 死亡快照　同一次事件派发内先后完成（HIGHEST 与 LOWEST）。
6
不掉落 B 条件判定　身上存在不掉落物/套装保护 → 整体接管，MVE 检测到空池自动中止；否则 MVE 托管 → 选择窗口开启（PVP 拾取同步可用）。
7
墓碑 C 接管　选择结束（保留/超时/放弃）→ 未保留物品重放掉落事件 → C 在死亡点收下它们、经验为 0；无人接手则原地掉落。
8
重生　B 还原回收物　MVE 返还保留物　各回各家，互不重叠。

铁律（结构性约束）

MVE 的生效时机夹在中间：比保留类模组更晚（LOW），比墓碑类更早（LOWEST 之前）。绝不可提到 HIGHEST——那是唯一会卷走保留物的位置。
缺席即自有归属：死亡快照里有、掉落池里没有的物品，MVE 一律标记“禁用”让位——这是对一切保留类模组的通用兼容，无需逐一适配。
条件回收时 MVE 整体中止：池空 ⇒ 无可托管 ⇒ 静默退出（含经验处理），把舞台完整让给 B。
结算重放是墓碑的唯一接管入口：MVE 结算时把未保留物品重放掉落事件，C 在 LOWEST 自然命中死亡快照建墓（位置=死亡点，经验=0）。
图腾在宣告前、互助在宣告时、MVE/墓碑在掉落时：三道关卡分属三个阶段，天然有序，互不抢戏。
